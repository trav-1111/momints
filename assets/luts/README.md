# Baked film LUT provenance

The five Momints PNGs are 32³ display-referred sRGB lookup tables, stored as 1024×32 RGB strips: `x = blue * 32 + red`, `y = green`. They are generated by `scripts/generate_film_luts.py`, not hand-authored proprietary emulsion measurements.

Verified generator source: [JanLohse/spectral_film_lut, revision 9d04d97ba8e20bfe00b72116e80ae19ab268dce3](https://github.com/JanLohse/spectral_film_lut/tree/9d04d97ba8e20bfe00b72116e80ae19ab268dce3), package version 0.17.1. The installed source revision was read from its `direct_url.json`; regenerating with that installed environment on 20 September 2026 matched all five frozen review hashes in `tests/fixtures/film/lut-manifest.json`. These assets are still untracked in the current working tree and must be included in the film change.

| Momints asset | Source negative/reversal             | Print stage            |
| ------------- | ------------------------------------ | ---------------------- |
| Aura 400      | `KODAK_PORTRA_400`                   | `KODAK_ENDURA_PREMIER` |
| Neon 800T     | `KODAK_5219`                         | `KODAK_2383`           |
| Vivid 50      | `FUJI_VELVIA_50`                     | None                   |
| Amber 200     | `KODAK_GOLD_200`                     | `KODAK_ENDURA_PREMIER` |
| Silver 400    | `KODAK_TRI_X_400`, inversion enabled | None                   |
| Bali 400      | `bali-400-v1.cube` (Portra 400 XMP)  | DaVinci/ACR (Trav)     |
| Martha        | `martha-v1.cube` (Resolve CUBE)      | DaVinci Resolve (Trav) |

All use `input_colorspace="sRGB"`, `gamma_func="sRGB"`. Bali 400 and Martha are compiled from the production 33-point CUBE profiles authored and supplied by Trav (`worker/filmstock-sources/{bali-400-v1,martha-v1}/source/`), resampled via trilinear interpolation into the 1024×32 format matching the runtime SkSL and OpenGL ES shaders. The legacy-named PNG duplicates are byte-identical to their Momints equivalents. Runtime catalog entries load the Momints files; legacy session IDs resolve to those entries.
